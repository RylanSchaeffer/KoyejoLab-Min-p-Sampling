# Confidential Note to the Action Editor (TMLR Submission 11062)

Dear Action Editor,

We are disclosing a possible anonymity issue.

The manuscript links to the public record of several exchanges with the original min-p authors: three GitHub issues (issues 4, 5 and 6 of `menhguin/minp_paper`) and one Telegram post by the original first author. The issue threads are the only public record of those exchanges. Opening them shows the GitHub username of the person who opened them, which could reveal one author's identity.

No reviewer indicated following the links. Reviewer wjeg wrote that the exchanges "cannot be verified from the paper." We kept the links in the revision because removing them would make the claims less verifiable.

Options:

1. Keep the links as they are.
2. Move the links to footnotes and describe each exchange in the text.
3. Replace the links with descriptions ("in a public issue on the original authors' repository, the authors stated that ...") and add the URLs in the camera-ready.

Please tell us which you prefer.

Sincerely,
The Authors
