# Confidential Note to the Action Editor (TMLR Submission 11062)

Dear Action Editor,

We would like to proactively disclose a potential anonymity concern with our submission so that you can decide how you would like us to handle it.

The manuscript documents several exchanges with the authors of the original min-p paper. Where a claim rests on such an exchange, we link to the public record of it. Three of those links point to issues on the original authors' GitHub repository (issues 4, 5 and 6 of `menhguin/minp_paper`), and one points to a public Telegram post by the original first author. The issue threads are the only public record of the exchanges they document, which is why we included them; however, opening those threads displays the GitHub username of the person who opened them, which could reveal one author's identity to a reader who follows the links.

We note that no reviewer has indicated they followed the links; one reviewer (wjeg) remarked that the exchanges "cannot be verified from the paper," which suggests the links were treated as external. We have kept the links in the revision because removing them would make those claims less verifiable, which is the opposite of what the reviewer asked for.

We are happy to handle this however you prefer. The options we see are:

1. Keep the links as they are.
2. Move the links to footnotes and describe each exchange in the text, so that verification requires an explicit choice to follow a footnote.
3. Replace the issue links with descriptions ("in a public issue on the original authors' repository, the authors stated that ...") and provide the URLs only in the camera-ready.

Please let us know if you would like us to adopt option 2 or 3, or something else. We apologize for any inconvenience.

Sincerely,
The Authors
